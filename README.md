# Student Performance Analytics & Visualization

A mini-project for **Data Science and Visualization** built around one dataset — a batch of
60 students across 4 semesters and 5 subjects — so that every syllabus unit and every listed
practical connects to the same working system instead of being a standalone exercise.

## What's inside

```
student-analytics-project/
├── data/
│   ├── generate_dataset.py     # creates the synthetic student dataset (with missing values)
│   └── students.csv            # generated dataset
├── analytics/
│   └── analytics.py            # descriptive stats, probability, sampling/estimation -> output.json
├── web/
│   ├── index.html              # dashboard shell
│   ├── style.css
│   ├── app.js                  # Canvas + SVG + Google Charts rendering
│   └── output.json             # generated by analytics.py — the dashboard's data source
└── README.md
```

## How to run

# 0. (macOS only) Create and activate a virtual environment.
#    macOS blocks "pip install" system-wide (PEP 668 / "externally-managed-environment"
#    error), so installing into a venv avoids that entirely.
python3 -m venv venv
source venv/bin/activate        # prompt should now show (venv)

# 1. Install dependencies into that environment
python3 -m pip install pandas numpy scipy

# 2. Generate the dataset (Practical 1 setup)
python3 data/generate_dataset.py

# 3. Run the analytics pipeline (Practicals 1-3)
python3 analytics/analytics.py

# 4. Serve the dashboard
#    (must be served over http:// — the page uses fetch() to load output.json,
#    which browsers block on a plain double-clicked file:// HTML page)
cd web
python3 -m http.server 8000
# then visit http://localhost:8000 in your browser
```

## How this maps to the syllabus

| Unit | Topic | Implementation |
|---|---|---|
| 1 | Intro to Business Analytics | README + dashboard overview section frame each feature as descriptive / predictive / prescriptive |
| 2 | Descriptive Analytics | `analytics.py::descriptive_stats()` — mean, median, quartiles, decile, variance, std dev, skewness, kurtosis, variation (max−min), per subject per semester |
| 3 | Probability | `analytics.py::probability_analysis()` — per-subject pass probability (PMF), a Binomial model over 5 subjects, Bayes' theorem (city vs. pass outcome), Normal fit for PDF/CDF |
| 4 | Sampling & Estimation | `analytics.py::sampling_and_estimation()` — 500-sample CLT demo, Method-of-Moments estimate, MLE estimate, required sample size for a target confidence interval |
| 5 | Data Visualization concepts | `web/app.js` — hand-built column chart, bar charts, pie chart, histogram (no charting library), following the chapter's charting primitives |
| 6 | Tabular Data Visualization | `web/app.js::renderTable()` — reads the processed data, renders a semantic `<table>`, dynamically highlights failing marks in red |
| 7 | Visualizing Data Programmatically | Column chart & histogram on **HTML5 Canvas**; pie/bar charts as **inline SVG**; city distribution as a **Google Charts** GeoChart |

## Notes

- The dataset is synthetic (seeded, so it's reproducible) — swap in a real class list by keeping
  the same CSV column names.
- Charts are built directly on the Canvas 2D API and raw SVG rather than a charting library, per
  Unit 5/7's "programmatic visualization" brief. Google Charts is used only for the GeoChart,
  matching the "Starting with Google Charts" section.
- Extend `analytics.py` with more distributions (Poisson, Exponential, Chi-Square, t, F) if your
  evaluator wants Unit 3 covered more exhaustively — the dataset already supports it.
